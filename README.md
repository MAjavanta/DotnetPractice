# Dotnet Practice

A series of projects done to teach myself .NET incrementally, focusing on SOLID principles and best practices.

1. Calculator - One file project learning the basic syntax and structure of Program.cs
2. ToDo App - Learning methods, loops, switch statements, validating user input.
3. Dice Rolle Game - Learning OOP, creating classes using the Single Responsibility Principle, using switch expressions, clean architecture, Dependency Injection
4. Cookies Cookbook - Implementing interfaces, sharp focus on clean code and well designed architecture, particularly looking at designing good interface for classes, reading and writing to file system best practices, using an enum with extension methods to easily switch between different file types. Using template method pattern and inheritance to remove code duplication and using repository pattern to hide implementation details.
5. CustomCache - implementing a custom cache class that works with generic types to make it more reusable. Also used the decorator design pattern to use the cache, allowing me to adhere to the Open-Closed principle.
6. CSV Reader - Working with external data sources and parsing CSVs.
7. API Stats - Working with external API
8. Game Store - a project separate from the solution to learn how to create RESTful APIs. The Game store project is started from a YouTube course.
